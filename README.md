# GitHub Achievements OmmniDevv

Repo ini mencatat perjalanan meraih GitHub Profile Achievements dengan cara legal:
kontribusi nyata, tanpa akun palsu, tanpa spam, tanpa star palsu.

## 8 achievement yang masih bisa diraih

- Pull Shark: PR yang di-merge (2 / 16 / 128 / 1024)
- Starstruck: repo buatan sendiri mencapai 16 / 128 / 512 / 4096 star
- Pair Extraordinaire: commit co-authored di PR yang di-merge (1 / 10 / 24 / 48)
- Galaxy Brain: jawaban Discussions yang diterima (2 / 8 / 16 / 32)
- Quickdraw: menutup issue atau PR dalam 5 menit setelah dibuka
- YOLO: merge PR sendiri tanpa review
- Public Sponsor: mensponsori kontributor open source lewat GitHub Sponsors
- Finishing Touch: PR yang di-merge dan dinilai meningkatkan kualitas UI GitHub

## Aturan main repo ini

- Setiap PR berisi perubahan beneran (dokumen, panduan, perbaikan).
- Tidak ada PR kosong, tidak ada issue spam.
- Progress dicatat di PROGRESS.md.
- Detail cara meraih tiap badge ada di ACHIEVEMENTS.md.
