# Panduan Tiap Achievement

## Pull Shark

Buka PR berisi perubahan nyata, lalu merge. PR ke repo sendiri tetap dihitung.
Tier: 2 (default), 16 (bronze), 128 (silver), 1024 (gold) PR yang di-merge.

## Quickdraw

Buka issue atau PR, lalu tutup dalam 5 menit. Paling gampang: buka issue
tentang perbaikan nyata, kerjakan, lalu tutup secepatnya.

## YOLO

Merge PR sendiri tanpa review apa pun. Hati-hati: review dari bot bisa
menggagalkan syarat ini, jadi merge PR yang bersih tanpa bot review.

## Pair Extraordinaire

Butuh commit dengan trailer `Co-authored-by: Nama <email>` di PR yang di-merge.
Co-author harus orang beneran yang ikut menulis perubahan itu, bukan nama tempelan.

## Galaxy Brain

Jawab pertanyaan di GitHub Discussions repo orang lain (bukan GitHub Community),
dan jawabanmu ditandai sebagai accepted answer oleh penanya.
Tier: 2 (default), 8 (bronze), 16 (silver), 32 (gold).

## Starstruck

Repo yang kamu buat sendiri mencapai 16 star. Tidak bisa dipaksa: repo harus
bermanfaat sampai orang lain mau memberi star dengan sukarela.

## Public Sponsor

Sponsori kontributor open source lewat GitHub Sponsors. Butuh dana beneran,
satu kali sponsor sudah cukup untuk badge dasar.

## Finishing Touch

PR yang di-merge dan dinilai meningkatkan kualitas UI GitHub sendiri.
Praktisnya ini berarti berkontribusi ke repo UI milik GitHub, jadi bukan
target yang realistis untuk dikejar cepat.
